# 📚 DivinePage

> **Read • Listen • Learn • Connect**

<div align="center">

An AI-powered open-source reading ecosystem that combines free books, AI narration, book communities, reading analytics, journals, AI assistants, and charity into one modern platform.

**Status:** 🚧 Planning Phase

</div>

---

# 🌍 Vision

DivinePage aims to become the world's most accessible free reading platform by combining modern AI with open knowledge.

Users can:

- 📖 Read books
- 🎧 Listen using AI narration
- 🤖 Ask AI about any chapter
- 👥 Join book communities
- 💬 Chat with readers
- 📚 Track reading progress
- ✍️ Maintain journals
- ❤️ Donate to support literacy

# 🚀 Tech Stack

| Layer | Technology |
|---------|------------|
| Frontend | Next.js 15 + React 19 + TypeScript |
| Mobile | React Native + Expo |
| Backend | Node.js + Express |
| Database | Supabase PostgreSQL |
| ORM | Prisma |
| Styling | Tailwind CSS v4 + NativeWind |
| Components | shadcn/ui |
| Animation | Framer Motion |
| Authentication | Supabase Auth |
| Realtime | Supabase Realtime + Socket.IO |
| Search | Meilisearch |
| Storage | Supabase Storage + Cloudinary |
| Notifications | Firebase Cloud Messaging |
| AI | Gemini 3.1 Pro |
| Voice | Microsoft Edge TTS + Piper |
| Deployment | Vercel + Railway + Supabase |
