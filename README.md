# 📚 DivinePage

### Read • Listen • Learn • Connect

An AI-powered, open-source reading ecosystem that enables everyone to **discover, read, listen, discuss, and share books** for free while building a global reading community.

# 🌍 Vision

DivinePage is designed to become the world's most accessible AI-powered digital library.

The platform combines:

- 📖 Free Book Reading
- 🎧 AI Audiobooks
- 🤖 AI Reading Assistant
- 👥 Reading Community
- 💬 Private & Group Chat
- 📚 Bookshelves
- ✍ Reading Journal
- 📈 Reading Analytics
- ❤️ Charity & Donations

---

# 🎯 Mission

Create a completely free reading ecosystem where anyone can:

- Read books
- Listen to books with AI narration
- Discover new books
- Join book clubs
- Discuss books with readers
- Track reading habits
- Save highlights & notes
- Receive AI explanations
- Receive AI recommendations
- Generate summaries
- Support literacy through donations

# 🤖 AI Development Rules

Before generating any code, every AI assistant must:

1. Read `.ai/MASTER_PRD.md`
2. Read `.ai/CODING_STANDARDS.md`
3. Read `.ai/SYSTEM_ARCHITECTURE.md`
4. Read `.ai/DATABASE_DESIGN.md`

After reading those files:

- Never modify unrelated files.
- Use TypeScript only.
- Follow SOLID principles.
- Follow Clean Architecture.
- Write reusable components.
- Write tests.
- Update documentation.
- Complete one task before starting another.
- Produce production-ready code only.
